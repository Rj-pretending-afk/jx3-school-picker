# 剑网3门派罗盘

综合“颜值”和“手感”两条偏好轴，为《剑网3》玩家推荐适合尝试的门派与心法。姊妹项目：[艾泽拉斯职业罗盘](https://github.com/Rj-pretending-afk/wow-class-picker)。

在线地址：<https://rj-pretending-afk.github.io/jx3-school-picker/>

## 功能

- 13 个固定方向，每个方向从 3 道同类题中随机抽 1 道（题库共 39 题），颜值题与手感题并行计分，各占最终契合度的 50%
- 所有题目可按顺序多选，点击顺序就是偏好优先级；每题都可选“我无所谓”
- 输出 10 个心法与 5 个门派推荐；“我无所谓”较多时优先推荐可切换职责的门派
- 覆盖正式服 20 个门派、31 个心法，门派介绍与心法介绍分开呈现，各自带优缺点
- 独立询问上手难度与操作上限，并为每个心法提供 0.0～9.0 的六维体验评分（上手难度、操作上限、操作节奏、轻功机动、生存容错、团队功能）
- 全心法评分图鉴：按门派、职责、距离筛选，可在六个维度间组合排序
- 右上角 `VII` 隐藏入口：江湖七宗罪鉴定，与正式评分完全隔离
- 纯前端、无需登录、适配手机与桌面

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 部署

`main` 分支通过 GitHub Actions 自动部署到 GitHub Pages。

- 藏剑的问水诀（轻剑）与山居剑意（重剑）在战斗中来回切换，合为一个输出方向。
